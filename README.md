# Xero Timesheet Guide

A one-page guide that shows Matrix casual workers how to submit their hours and kilometres in Xero.

- `index.html`: the whole guide. Open it in a browser, or host the folder on any static host (GitHub Pages).
- `img/`: the pictures the guide uses.
- `tools/`: scripts that cut the pictures from the original screenshots, place the marks and record picture sizes.
- [`GUIDE-PRINCIPLES.md`](GUIDE-PRINCIPLES.md): design rules shared by every Matrix guide. Same file in each guide repository.
- [`DESIGN.md`](DESIGN.md): what is special about this guide. **Read both before changing anything.**
- [`AGENTS.md`](AGENTS.md): short working rules for AI agents.

There is no build step. Edit `index.html` and reload.

The page stores nothing in the browser and sends nothing anywhere. The original, unredacted screenshots are not in
this repository.
